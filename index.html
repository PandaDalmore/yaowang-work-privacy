《妖王也要打工》Windows 试玩版隐私政策

版本日期：2026年11月7日

本政策说明《妖王也要打工》Windows 试玩版（以下简称“本游戏”）如何处理与您有关的信息。本游戏的运营者为吴力群，TapTap 开发者展示名称为“达尔进化论”。您可通过 wlq3729930@163.com 联系我们，咨询本政策或提出个人信息相关请求。

一、本地游戏数据

本游戏的生活模拟玩法在本地运行。游戏会在您电脑的用户数据目录中保存游戏进度、物品、任务、居民互动记录、游戏内时间以及显示和操作设置，用于继续游戏及保留您的偏好。上述游戏数据不是您的现实身份信息，但可能包含您在游戏中输入或形成的内容。

当前版本的游戏业务代码未设置将这些存档上传至开发者服务器的功能，也未集成开发者自行运营的账号系统、广告 SDK 或统计分析服务。游戏不要求您向开发者提供身份证、手机号、通讯录、精确位置、照片、麦克风或摄像头数据。

二、TapTap 平台与启动校验

本游戏通过 TapTap Windows 客户端分发，并集成 TapTap PC SDK 的启动校验功能。该功能用于确认游戏是否由 TapTap 客户端启动、接收平台运行状态以及账号是否可游玩的结果；校验未通过时，游戏可能无法继续运行。

当前游戏接入代码使用启动校验和平台状态回调，接收校验结果、平台是否运行及当前账号是否可游玩的状态。未接入获取玩家昵称、手机号、实名认证资料或好友列表的功能，也未接入 TapTap 数据分析、广告、云存档或在线对战功能。

SDK 名称：TapTap PC SDK（C++，4.6.1）；服务提供者：易玩（上海）网络科技有限公司。接入目的为启动校验和运行状态判断。平台登录、资格管理与平台服务中的信息处理适用 TapTap 的相应政策。您可以在使用前查阅 TapSDK 隐私政策，并查看 TapTap 客户端内的隐私政策。该 SDK 官方政策按不同服务介绍处理范围，移动端专属字段不代表本 Windows 游戏接入了对应移动端功能。

游戏下载、平台登录及校验涉及的联网行为，与本地核心玩法是不同环节。本游戏没有内购，不在游戏内提供在线 AI 内容生成服务。

三、主动联系我们时提供的信息

当您通过邮箱反馈问题时，我们会接收您主动提供的邮箱地址、反馈内容及附件，用于回复和排查问题。您无需提供与问题无关的个人信息。若需发送存档、截图或日志，请先检查并移除无关的私人内容。

我们只在处理该事项及必要的后续沟通期间保留这些反馈；事项结束后，不再需要的信息将予以删除或匿名化，法律法规另有要求的除外。

四、共享、转让与披露

我们不会出售您的个人信息，也不会将您的反馈用于广告画像或商业营销。除您另行同意、履行适用法律义务或处理您的请求所必需的情形外，不主动向其他主体提供您的反馈信息。TapTap 平台自身提供服务所涉及的信息处理，适用其对应政策。

五、保存、安全与您的选择

游戏存档及设置保存在本机。卸载游戏是否同时移除用户数据，取决于客户端和卸载方式；删除存档前请自行备份。我们目前不提供开发者服务器上的云存档恢复服务。

您可以通过游戏内提供的设置管理显示和操作偏好；如需删除本地进度，可在确认备份后删除对应存档文件。涉及您主动发送给我们的反馈，您可通过上述邮箱申请查阅、更正或删除，或咨询处理方式。我们会在合理期限内核实并处理您的请求，并按适用法律要求回复。

六、未成年人保护

游戏的申报适龄分级为12周岁以上。适龄分级不等同于平台下载资格或防沉迷准入条件。本次发行拟采用 TapTap 平台通用防沉迷方案，是否可下载、启动或游玩及相应限制，以平台实际审核和执行结果为准。

未成年人应在监护人指导下使用本游戏。监护人如认为未成年人向我们提供了不适当的个人信息，可通过联系邮箱请求处理。

七、政策更新与联系

如数据处理方式发生实质变化，我们会在游戏内或商店公告等适当位置说明，并更新本政策。需要另行取得同意的情形，将依法另行处理。
